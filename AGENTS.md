# Brasil em Desenvolvimento

Projeto gratuito de investigação e planejamento territorial. Código principal: index.html. Notas públicas: vault/Brasil em Desenvolvimento. Não publicar cofre pessoal, chaves ou conteúdo local do navegador.

Skills do projeto estão em .agents/skills. Use analisar-infraestrutura-brasil para diagnósticos, cartografia-oficial-brasil para geometrias e camadas, curar-conhecimento-territorial para notas e formular-projetos-territoriais para propostas. Leia apenas as que se aplicam à tarefa.

O site usa resumos desses modos no Jarvis; isso não instala ferramentas nem dá acesso automático ao Obsidian. Referências, datas e limites de cobertura devem acompanhar as informações apresentadas.

Validação: node --check em scripts alterados e testes Playwright em tests/e2e.js. Compile notas explicitamente públicas com node scripts/build-knowledge.js. Mantenha o site no GitHub Pages e preserve dados pessoais locais.
